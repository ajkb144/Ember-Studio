# Books & Clinical Literature Archive (Block 0A)

This directory houses granular clinical extractions and somatic micro-practice breakdowns from foundational clinical literature (Polyvagal Theory, Somatic Experiencing, Interoception, Sensorimotor Psychotherapy).

## Structured Extraction Schema:
Each literature extraction markdown file should contain:
- **Source Citation:** Title, Author, Year, Core Philosophy
- **Physiological Mechanism:** Exact vagal/nervous system pathway activated (e.g., ventral vagal activation, dorsal vagal discharge)
- **Target Micro-Practice:** Physical instruction (duration, biomechanical cue, breath ratio)
- **Contraindications & Flags:** Populations or dysregulation states where this practice is unsuited
- **Spiritual / Witnessing Bridge:** How this physiological shift naturally opens into non-dual presence (*Sakshi*, *Sehaj*, Christ Consciousness, Witnessing)
