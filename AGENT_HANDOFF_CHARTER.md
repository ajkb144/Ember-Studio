## 1. Core Operating Model: Asynchronous Chronological Pipeline
This project operates on **high-leverage parallel execution with strict chronological dependency gates**.
- **Amanjot (Creative Director & Decision Maker):** Owns 100% of the vision, somatic/clinical accuracy, linguistic nuance, `SKILL.md`, and final taste approvals starting from Phase 0 / Block 0 onwards.
- **Antigravity Agent (AI Executor):** Executes research scraping, knowledge synthesis, Python audio engineering, and FFmpeg video compositing in the background once decisions are locked.

### THE 5 OPERATING LAWS FOR THE AGENT:
1. **Lock Decisions -> Execute in Background -> Advance:** Amanjot should never be blocked waiting for AI execution. As soon as Amanjot closes the open questions for Stage $N$, immediately begin executing Stage $N$ in the background while presenting the decision checklist for Stage $N+1$ (or any independent parallel track).
2. **Respect Cohesive Dependencies:** While independent utility tasks (like building the Python healing frequency synthesizer or scraping viral reels) can run in parallel, cohesive content production must follow strict chronological dependency:
   `Knowledge & Viral Research` + `SKILL.md` $\rightarrow$ `Cohesive Script & Visual Concept` $\rightarrow$ `Voice Recording + Master Audio Mix` $\rightarrow$ `Cohesive Video Assembly`.
3. **Zero Assumptions Rule (Open vs. Closed Ledger):** Never assume sources, keywords, script styles, or visual pairings. Before running any research or generation task, explicitly output:
   - **Closed Decisions:** What we have already locked.
   - **Open Questions:** What requires Amanjot’s sign-off before execution.
4. **Zero "AI Slop" Tolerance:** Do not generate generic wellness clichés or robotic translations. `SKILL.md` is authored by Amanjot. All scripts and visual pairings must function as a single cohesive somatic experience.
5. **Continuous Recalibration:** At the completion of every background task, present a concise summary of outputs so Amanjot can recalibrate before those outputs feed into the next dependent stage.
