# Gemini Brainstorming Handoff Suite

This directory contains standalone, copy-pasteable mission briefs and deliberation prompts designed for Amanjot to take to specialized Gemini brainstorming chats.

## Operating Workflow:
1. **Open a Handoff Document:**
   - For **Block 0 (Clinical & Viral Research)**: Use [`BLOCK_0_RESEARCH_HANDOFF.md`](file:///c:/Users/Amanjot%20Kaur/Documents/Antigravity%20projects/Ember%20Studio%20144/brainstorming_handoffs/BLOCK_0_RESEARCH_HANDOFF.md)
   - For **Block 2 (Sound & Audio Engine)**: Use [`BLOCK_2_AUDIO_ENGINE_HANDOFF.md`](file:///c:/Users/Amanjot%20Kaur/Documents/Antigravity%20projects/Ember%20Studio%20144/brainstorming_handoffs/BLOCK_2_AUDIO_ENGINE_HANDOFF.md)
2. **Copy & Paste into Gemini:**
   - Copy the entire code block inside the handoff document and paste it into a new Gemini chat.
3. **Brainstorm & Deliberate:**
   - Gemini acts as your specialized co-pilot, presenting clinical, acoustic, and algorithmic trade-offs so you can make informed decisions.
4. **Export the Lock Sheet:**
   - At the end of the brainstorming session, Gemini will output the structured **Decision Gate Lock Sheet**.
5. **Paste Back to Antigravity:**
   - Paste the Lock Sheet into this Antigravity chat. Antigravity will immediately lock the gate, launch execution in the background, and advance to the next stage.
